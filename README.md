# UNIQUEL BAGS

Каталог и защищённая панель управления на React / Vinext. Товары хранятся в SQLite, загруженные фотографии — на постоянном диске. Проект настроен для standalone Node.js-сервера и развёртывания на Fly.io.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env
# Задайте ADMIN_EMAIL, ADMIN_PASSWORD и SESSION_SECRET в .env
npm run dev
```

Проверки перед публикацией:

```bash
npm test
npm run lint
npx tsc --noEmit
npm run build
npm start
```

По умолчанию SQLite и фотографии сохраняются в `./data`. Каталог можно изменить переменной `DATA_DIR`.

## Форматирование кода

Используется Prettier со стандартными настройками: отступы в два пробела, двойные кавычки, точки с запятой и перенос строк при ширине 80 символов.

```bash
npm run format        # Отформатировать код
npm run format:check  # Проверить форматирование без изменения файлов
```

Сгенерированные файлы, зависимости, локальные данные, статические ресурсы и lock-файлы исключены через `.prettierignore`.

## Администратор

В `/admin` используются email и пароль из `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Доступ к изменению товаров и загрузке фотографий проверяется на сервере. Сессия подписывается секретом `SESSION_SECRET` длиной не менее 32 символов и хранится в HttpOnly-cookie в течение 7 дней.

## Товары

Добавление и редактирование: название, фото (JPG/PNG/WebP до 8 МБ или HTTPS-ссылка), категория, материал, несколько цветов с отдельными фотографиями, цена, старая цена, описание, размер, наличие и метка. Скрытые товары перемещаются в архив и могут быть восстановлены. Фильтры каталога используются сохранённые характеристики.

Чтобы добавить варианты одной модели, отметьте цвет: он автоматически выбирается для следующей загрузки. Для каждого цвета можно добавить до 10 фотографий: загрузите файлы по одному или добавьте HTTPS-ссылки. Выберите миниатюру в редакторе, чтобы кадрировать или удалить нужное фото. Первое фото товара становится обложкой, а первое фото цвета показывается на карточке каталога. В каталоге фотографии выбранного цвета автоматически сменяются каждые 3,5 секунды; положение указателя над фото выбирает кадр слева направо. Смена приостанавливается при наведении, фокусе, открытом диалоге, скрытой вкладке и вне экрана. Смена фотографий сопровождается плавным затуханием без отдельной кнопки паузы; при включённом уменьшении движения автоматическая смена и анимация отключены. Покупатель также может переключать цвета и фотографии в открытой карточке. В корзине и тексте заказа сохраняется выбранный цвет. Цена и наличие общие для всех цветов модели.

При загрузке файла открывается редактор фото: выберите формат (4:5, квадрат или пропорции оригинала), настройте масштаб и положение перетаскиванием либо ползунками. «Применить фото» загрузит выбранный кадр; в каталоге он появится после сохранения товара. Кнопка «Кадрировать и переместить» повторно открывает редактор, а значок карандаша рядом с основным фото позволяет редактировать обложку отдельно. Фото по внешней ссылке можно обработать, только если сайт разрешает CORS; иначе скачайте его и загрузите файлом. Редактор сохраняет новый JPEG до 2000 пикселей по длинной стороне без увеличения исходного разрешения. Повторное редактирование использует уже обрезанное фото; чтобы вернуть отсечённые области, загрузите оригинал снова.

При первом запуске в пустой базе появляются 9 явно обозначенных демонстрационных моделей с иллюстративными фотографиями. Их можно отредактировать или скрыть. Демонстрационная коллекция не описывает реальные остатки магазина.

Заказ обсуждается в WhatsApp магазина. Онлайн-оплата не подключена. Избранное хранится на устройстве, корзина существует в текущей вкладке.

## Развёртывание на Fly.io

1. Установите и авторизуйте `flyctl`.
2. При необходимости измените глобально уникальные значения `app` и `APP_URL` в `fly.toml` и имя приложения в командах ниже.
3. Создайте приложение и постоянный диск:

   ```bash
   fly apps create uniquel-bags
   fly volumes create uniquel_bags_data --region ams --size 10
   ```

4. Задайте секреты, подставив собственный email и длинный случайный пароль:

   ```bash
   fly secrets set \
     ADMIN_EMAIL="admin@example.com" \
     ADMIN_PASSWORD="замените-на-длинный-случайный-пароль" \
     SESSION_SECRET="$(openssl rand -hex 32)"
   ```

5. Запустите одну Machine: SQLite и локальный Volume рассчитаны на один писатель.

   ```bash
   fly deploy --ha=false
   ```

Приложение слушает порт 8080. Проверка состояния доступна по `/api/health`. Регион по умолчанию — Амстердам (`ams`), конфигурация — `shared-cpu-1x` с 1 ГБ RAM и Volume на 10 ГБ.

Не увеличивайте количество Machines без замены способа хранения: Volume подключается только к одной Machine, а отдельные SQLite-файлы не синхронизируются автоматически. Перед обновлением `fly.toml` для собственного домена обновите также `APP_URL`.

Существующие данные из Cloudflare D1 и R2 автоматически не переносятся. Если каталог уже наполнен, экспортируйте товары и фотографии отдельно до переключения: при пустой SQLite приложение добавит демонстрационную коллекцию.

## Резервные копии

Fly.io автоматически хранит снапшоты Volume пять дней, но они не заменяют независимую резервную копию. Регулярно копируйте из `/data` файлы `catalog.sqlite`, `catalog.sqlite-wal`, `catalog.sqlite-shm` (при их наличии) и каталог `images` во внешнее хранилище. Для консистентной копии SQLite используйте SQLite Online Backup API или сначала выполните `PRAGMA wal_checkpoint(TRUNCATE)` при остановленных записях. Периодически проверяйте восстановление.
