# UNIQUEL BAGS

Каталог и защищённая панель управления на React / Vinext. Товары хранятся в D1, загруженные фотографии — в R2.

## Запуск

- npm install
- npm run dev
- npm run build
- npx tsc --noEmit

## Администратор

В /admin войдите через ChatGPT с email, указанным в серверной переменной ADMIN_EMAIL. Разрешения проверяются для всех запросов изменения товаров и загрузки фото. В продакшене переменная задаётся через Sites; отсутствие переменной закрывает доступ. В локальном режиме Sites имитирует тестовый аккаунт, которому доступ к админке не разрешён.

## Товары

Добавление и редактирование: название, фото (JPG/PNG/WebP до 8 МБ или HTTPS-ссылка), категория, материал, несколько цветов с отдельными фотографиями, цена, старая цена, описание, наличие и метка. Скрытые товары перемещаются в архив и могут быть восстановлены. Фильтры каталога используют сохранённые характеристики.

Чтобы добавить варианты одной модели, отметьте цвета и выберите цвет в поле «Фото для цвета» или нажмите на его миниатюру. Загрузите фотографию или укажите HTTPS-ссылку для каждого цвета. Цвет без отдельного фото использует основное фото. Покупатель может переключать цвета в каталоге и открытой карточке; в корзине и тексте заказа сохраняется выбранный цвет. Цена и наличие общие для всех цветов модели.

При первом запуске в пустой базе появляются 9 явно обозначенных демонстрационных моделей с иллюстративными фотографиями. Их можно отредактировать или скрыть. Демонстрационная коллекция не описывает реальные остатки магазина.

Заказ обсуждается в WhatsApp магазина. Онлайн-оплата не подключена. Избранное хранится на устройстве, корзина существует в текущей вкладке.
